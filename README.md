# Savora — Premium Restaurant Website

A responsive restaurant website demo built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Project files

- `index.html` — all page sections, dish cards, reservation form, cart drawer, and footer.
- `style.css` — design system, advanced responsive styling, animations, and mobile layouts.
- `script.js` — mobile navigation, menu filters, cart quantities/totals, demo reservation validation, review slider, and reveal animations.

## Run locally

1. Extract the ZIP file.
2. Open the `savora-restaurant-website` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use the Live Server extension.
4. Edit text, prices, contact information, and images before presenting it to a real client.

## Important before using this for a real client

This is a front-end demo. The cart is held in browser memory, the reservation form does not send data to a restaurant, and checkout does not take payment. A real launch needs a secure backend/API, server-side validation, data storage, spam protection, and a payment/order provider if online payments are required. Never store payment card details yourself.

## Customisation

- Main colours and fonts are set at the top of `style.css` in `:root`.
- Dish names, categories, descriptions, prices, and image URLs are in `index.html`.
- Interaction logic is in `script.js`.
- Replace the sample business address, phone number, email, reviews, and menu details with client-approved content.
- Google Fonts and Unsplash images require an internet connection.
